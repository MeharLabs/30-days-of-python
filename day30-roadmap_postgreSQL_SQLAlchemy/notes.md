## 📅 Roadmap - 30 Days Plan

### **Week 1 - PostgreSQL Fundamentals (Days 1–7)**
- Day 1 - Install PostgreSQL, psql CLI, create first DB
- Day 2 - Tables: CREATE, ALTER, DROP - Data Types
- Day 3 - CRUD: INSERT, SELECT, UPDATE, DELETE
- Day 4 - Filtering: WHERE, AND/OR, LIKE, IN, BETWEEN
- Day 5 - Sorting & Limiting: ORDER BY, LIMIT, OFFSET
- Day 6 - Aggregate Functions: COUNT, SUM, AVG, MIN, MAX, GROUP BY
- Day 7 - Practice Project: Design a simple `users` + `posts` schema

---

### **Week 2 - Intermediate SQL (Days 8–14)**
- Day 8 - JOINs: INNER, LEFT, RIGHT, FULL OUTER
- Day 9 - Subqueries & Nested Queries
- Day 10 - Constraints: PRIMARY KEY, FOREIGN KEY, UNIQUE, NOT NULL, CHECK
- Day 11 - Indexes - what they are and when to use them
- Day 12 - Transactions: BEGIN, COMMIT, ROLLBACK
- Day 13 - Views & CTEs (Common Table Expressions)
- Day 14 - Practice Project: Blog DB with users, posts, comments, tags

---

### **Week 3 - SQLAlchemy Core + ORM (Days 15–21)**
- Day 15 - What is SQLAlchemy? Core vs ORM - Setup & Connection
- Day 16 - Defining Models with `DeclarativeBase`
- Day 17 - Session: add, commit, rollback - CRUD with ORM
- Day 18 - Querying: `select()`, `filter()`, `where()`, `scalar()`
- Day 19 - Relationships: `relationship()`, `ForeignKey`, lazy/eager loading
- Day 20 - Migrations with **Alembic** - `init`, `revision`, `upgrade`
- Day 21 - Practice Project: ORM version of Blog DB

---

### **Week 4 - Advanced Patterns + Real Projects (Days 22–30)**
- Day 22 - Advanced Querying: joins in ORM, `joinedload`, `subqueryload`
- Day 23 - Pagination, Ordering, Aggregates via ORM
- Day 24 - SQLAlchemy + FastAPI integration (async sessions)
- Day 25 - Connection Pooling, Engine config best practices
- Day 26 - Raw SQL with SQLAlchemy (`text()`)
- Day 27 - Testing DB code - pytest + test DB setup
- Day 28 - Many-to-Many relationships (association tables)
- Day 29 - Full project: **Mini Blog API** - FastAPI + SQLAlchemy + PostgreSQL
- Day 30 - Review, clean code, README, wrap-up


## 🛠️ Tools to Use

```
PostgreSQL        - The database engine
psql              - CLI to interact with Postgres
pgAdmin / DBeaver - GUI client (optional but helpful)
SQLAlchemy 2.x    - Python ORM / SQL toolkit
Alembic           - DB migration tool
psycopg2          - PostgreSQL driver for Python
FastAPI           - For real API integration (Week 4)
pytest            - For testing DB logic
```
